# Headings

This is the structure of headings on this page. Make sure the headings follow the correct hierarchy - a single `h1`, followed by `h2`/`h3` subheadings in a logical order, with nothing skipped.

This tab lists every heading found on the page in document order, so authors without an HTML background can spot a missing `h1` or an out-of-order subheading at a glance.
