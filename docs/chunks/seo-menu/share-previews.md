# Share previews

Get a preview of how your page will look for other people when shared on different social platforms.

Using the page's existing meta tags (title, description, and `og:image`/`twitter:image`), this tab renders a preview of the shared link card for:

- Facebook
- Twitter (X)
- LinkedIn
- Discord
- WhatsApp

::: tip
If a page is missing a social image, the preview will show "No social image provided" so authors know to add one before sharing the page.
:::
