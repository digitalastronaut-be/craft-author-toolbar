# Base checklist

This is a basic checklist that all pages should try to check off for a well maintained SEO performance. It checks the current page for:

- **Title** - present, and under 60 characters.
- **Meta description** - present, and between 120-160 characters.
- **H1 heading** - exactly one, and under 70 characters.
- **Subheadings** - the page contains `h2`/`h3` tags.
- **Main content** - a `<main>` element is present and contains at least 300 words.
- **Images** - the page has images, and they all have descriptive alt text.
- **Links** - the page links to at least one internal or external page.
- **Social images** - `og:image` and `twitter:image` meta tags are both present.

Each item shows as passed, a warning, or failed, so authors can see exactly what to fix without needing any SEO background.
