# SEO menu

The SEO menu gives authors a basic SEO health check for the page they're currently viewing, without needing any other SEO plugin installed. The toggle button shows an at-a-glance passed/warning/failed status, and the menu itself is split into four tabs:

1. [Base checklist](/chunks/seo-menu/base-checklist) - the core on-page checks (title, meta description, headings, images, links, social images).
2. [Share previews](/chunks/seo-menu/share-previews) - a preview of how the page will look when shared on social platforms.
3. [Images](/chunks/seo-menu/image-analytics) - an overview of every image on the page and potential issues with them.
4. [Headings](/chunks/seo-menu/headings) - the page's heading structure.

::: tip
Access to the SEO menu is controlled by the `author-toolbar:access-seo-menu` permission, and it can be disabled entirely via the `seoMenuEnabled` setting.
:::
