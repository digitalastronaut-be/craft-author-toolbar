# Help menu

The help menu gives authors a quick way to get in touch or report a problem without leaving the page they're working on.

Its contents are driven entirely by the `Author toolbar > Settings` page:

- **Information** - free-form text (and an optional company logo) shown at the top of the menu.
- **Company, Email, Phone number** - contact details shown as a short list. Each field is only shown if it's filled in.
- **Issue ticket URL** - if set, shows a "Create a bug report or feature request" button that links authors straight to your bug tracker.

::: tip
Any of these fields can be left empty. The menu only renders the sections you've actually configured.
:::
